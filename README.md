# Decentralized Voting System

A secure, transparent, and tamper-proof voting application built on the Ethereum blockchain using Solidity, Hardhat, Ethers.js, and React.

## 🌟 Features
- **Blockchain Security**: All votes are stored immutably on the Ethereum blockchain, ensuring transparency and security.
- **Single Vote Enforcement**: Smart contracts enforce a strict one-vote-per-address rule, preventing double voting.
- **Admin Controls**: A designated admin account can securely add candidates.
- **Real-Time Results**: The voting interface instantly reflects current vote counts dynamically.
- **Auto-Winner Calculation**: Once the deadline closes, the contract allows users to verify and retrieve the correct winner.

## 🛠️ Tech Stack
- **Smart Contract**: Solidity
- **Environment**: Hardhat (Local blockchain node)
- **Frontend**: React (Vite) + Ethers.js (v6)
- **Wallet Integration**: MetaMask

## 🚀 Setup Instructions

### 1. Prerequisites
- Node.js installed (v18+ recommended)
- MetaMask extension installed in your browser

### 2. Install Project Dependencies
Open a terminal in the root directory:
```bash
# Install Hardhat dependencies
npm install

# Install Frontend dependencies
cd frontend
npm install
```

### 3. Start Local Blockchain
In the root directory, start the Hardhat node. This creates a local Ethereum network with 20 dummy accounts.
```bash
npx hardhat node
```
*Keep this terminal open.*

### 4. Configure MetaMask
1. Open MetaMask -> Settings -> Networks -> Add a network manually.
2. Network Name: `Hardhat Localhost`
3. New RPC URL: `http://127.0.0.1:8545/`
4. Chain ID: `31337`
5. Currency Symbol: `ETH`
6. Click **Save** and switch to this network.
7. Import one of the private keys generated by the `npx hardhat node` into MetaMask to have test ETH (Account #0 will be the Admin).

### 5. Deploy Smart Contract
Open a *new* terminal in the root directory and run:
```bash
npx hardhat run scripts/deploy.js --network localhost
```
*Note: This script will deploy the Voting contract and automatically copy the ABI (`Voting.json`) and contract address (`contract-address.json`) into the React frontend folder (`frontend/src/contracts/`).*

### 6. Run the Frontend App
Open a terminal in the `frontend` directory:
```bash
npm run dev
```

Open your browser to `http://localhost:5173`. 
- Ensure your MetaMask is connected to the `Hardhat Localhost` network.
- Use Account #0 to add candidates. The admin is the one who deploys the contract.
- Switch to Account #1 or #2 in MetaMask to cast votes.
- Once the duration ends, click "Reveal Winner".

## 🧾 How it Works under the hood

1. **How blockchain ensures security:**
The decentralized nature of Ethereum implies there is no centralized database holding vote data. The state transitions regarding who voted and the vote counts are verified by the network, preventing malicious data mutation.

2. **How double voting is prevented:**
The Solidity smart contract uses a state mapping: `mapping(address => bool) public voters`. When a user votes, `voters[msg.sender]` is set to `true`. Every subsequent attempt triggers a `require(!voters[msg.sender], "You have already voted")` failing the transaction explicitly and refunding any extra gas.

3. **How transparency is achieved:**
Every change of state (e.g. adding candidates, voting) is recorded on the public ledger. Furthermore, a Solidity event `Voted(address voter, uint candidateId)` is emitted with every successful vote to track voting activities transparently.
